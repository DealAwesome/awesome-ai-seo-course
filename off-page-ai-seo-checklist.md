# Off-Page AI SEO Checklist

- [ ] Identify recurring cited domains
- [ ] Identify competitor mentions
- [ ] Separate backlinks from unlinked mentions
- [ ] Separate AI citations from generic mentions
- [ ] Classify source types
- [ ] Find relevant industry publications
- [ ] Find useful comparison resources
- [ ] Find legitimate directories
- [ ] Find relevant communities/forums
- [ ] Find documentation/research sources
- [ ] Create information worth referencing
- [ ] Prefer original data/experiments over generic guest-post pitches
- [ ] Keep entity facts consistent across placements
- [ ] Monitor whether referring pages remain indexed
- [ ] Monitor whether citation/source patterns change
- [ ] Record traffic/leads where possible

## Avoid

- Irrelevant mass placements
- Fake reviews/testimonials
- Fabricated expert quotes
- Duplicate parasite articles
- Exact-match anchor spam
- Treating DR/DA as the only quality signal
