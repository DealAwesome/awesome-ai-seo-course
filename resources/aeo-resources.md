# AEO Resources

Answer Engine Optimisation (AEO) generally focuses on making information suitable for direct-answer and answer-oriented discovery.

## Core Concepts

- clear definitions
- concise answer passages
- descriptive headings
- entity clarity
- factual support
- useful tables/lists
- structured data where accurate
- answer-oriented query research
