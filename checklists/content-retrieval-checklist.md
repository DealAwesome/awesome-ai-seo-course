# Content Retrieval Checklist

Before publishing an important AI SEO page:

- [ ] Primary entity/topic is explicit
- [ ] Main question is answered early
- [ ] Headings are descriptive
- [ ] Key passages can stand alone
- [ ] Definitions are concise and precise
- [ ] Factual claims have appropriate sources
- [ ] Original analysis is distinguished from sourced fact
- [ ] Tables are used only when comparison helps
- [ ] Lists are used for workflows/checklists
- [ ] Important content is visible in HTML
- [ ] Page is crawlable
- [ ] Page is indexable
- [ ] Canonical is correct
- [ ] Internal anchors describe the destination
- [ ] Entities are named consistently
- [ ] Structured data matches visible content
- [ ] Page adds information beyond generic AI prose
- [ ] Page has a useful next action

## Quick Test

Can someone copy one important paragraph out of context and still understand:
1. what entity/topic it is about;
2. what the answer is;
3. what evidence supports it?

If not, rewrite the passage.
