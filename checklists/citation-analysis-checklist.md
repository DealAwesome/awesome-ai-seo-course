# AI Citation Analysis Checklist

## Build the Query Set

- [ ] Informational queries
- [ ] Commercial queries
- [ ] Comparison queries
- [ ] Recommendation queries
- [ ] Brand queries
- [ ] Competitor queries
- [ ] Trust-validation queries

## Run and Record

For each query:

- [ ] Record date/time
- [ ] Record platform/surface
- [ ] Record brands mentioned
- [ ] Record cited domains
- [ ] Record cited URLs
- [ ] Record source type
- [ ] Record competitor visibility
- [ ] Record mention context/sentiment
- [ ] Save notes/screenshots where useful

## Analyse

- [ ] Which domains recur?
- [ ] Which URLs recur?
- [ ] Which source types recur?
- [ ] Which competitors dominate?
- [ ] Which queries show no brand visibility?
- [ ] Are owned pages eligible but absent?
- [ ] Are third-party source gaps obvious?

## Act

- [ ] Improve owned content where appropriate
- [ ] Improve entity consistency
- [ ] Add genuine information gain
- [ ] Pursue relevant third-party coverage
- [ ] Earn legitimate links/mentions
- [ ] Re-run the same query set

## Rule

One AI answer is an observation, not a stable visibility measurement.
