# AI SEO Course Evaluation Checklist

Use this before paying for an AI SEO course.

## Curriculum

- [ ] Covers traditional SEO fundamentals
- [ ] Covers AI-search behaviour beyond AI-assisted writing
- [ ] Covers GEO and/or AEO with practical examples
- [ ] Explains retrieval and source/citation analysis
- [ ] Covers entities and brand authority
- [ ] Covers off-page source ecosystems
- [ ] Covers AI visibility measurement
- [ ] Covers testing/experimentation
- [ ] Includes a clear update date

## Evidence

- [ ] Instructor/provider experience can be verified
- [ ] Examples are genuine
- [ ] Tests/experiments explain methodology
- [ ] Results are not presented without evidence
- [ ] Missing facts are marked unknown/unverified

## Product Fit

- [ ] Format fits how I learn
- [ ] Price matches what I actually need
- [ ] I need the offered live support/community
- [ ] Certificate matters for my use case
- [ ] Refund/renewal terms are clear
- [ ] I can apply the material to a real project

## Red Flags

- [ ] “AI SEO” mostly means ChatGPT content generation
- [ ] GEO/AEO is in the title but absent from curriculum
- [ ] Guaranteed citations/rankings
- [ ] Hidden affiliate relationships
- [ ] Unverifiable testimonials/results
- [ ] No measurement framework
- [ ] Stale screenshots/platform terminology
