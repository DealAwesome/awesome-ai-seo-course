# Contributing

Thanks for helping improve **Awesome AI SEO Course Resources**.

## Good Contributions

- new legitimate AI SEO/GEO/AEO courses;
- corrected prices or access terms;
- curriculum updates;
- broken-link fixes;
- new free resources;
- useful templates/checklists;
- documented experiments;
- source corrections.

## Course Submission Format

Please provide:

- **Course name**
- **Provider**
- **Instructor** (if verified)
- **Official URL**
- **Format**: self-paced / cohort / community / manual / academy
- **Price**: current price or `Unverified`
- **AI-search topics**: GEO / AEO / citations / entities / measurement
- **Last checked**: `YYYY-MM-DD`
- **Source URL**
- **Notes**

## Evidence Rules

1. Use the provider's official page where possible.
2. Do not convert missing information into `No`; use `Unverified`.
3. Date volatile fields such as price, lesson count and membership count.
4. Separate provider claims from independently verified facts.
5. Disclose commercial/affiliate relationships.
6. Do not add fabricated reviews, results or testimonials.
7. Keep descriptions factual and concise.

## Pull Requests

A good pull request explains:
- what changed;
- why;
- the source used;
- the date verified.

By contributing, you agree that your contribution can be published under the repository's licence.
